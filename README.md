# FAKE-NEWS-DETECTOR

A Machine Learning project built to detect fake news using Python and Scikit-Learn.

## 🚀 About the Project
This project uses Natural Language Processing (NLP) and a Machine Learning classifier to analyze news articles and determine whether they are real or fake.

## 🛠️ Tech Stack
* *Language:* Python
* *Environment:* Google Colab / Jupyter Notebook
* *Libraries:* Scikit-Learn (PassiveAggressiveClassifier, TfidfVectorizer), Pandas, NumPy

## 💻 How to Run
1. Download or clone the .ipynb file from this repository.
2. Open it in Google Colab or any Jupyter environment.
3. Run the code cells sequentially to preprocess data and test inputs.
